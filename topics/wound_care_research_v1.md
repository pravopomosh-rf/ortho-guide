# Обработка послеоперационных ран — конспект доказательств (v1, 08.11.2026)

Назначение: основа для обновления страницы ops/dressings.html и видео «Перевязка».
Уровни: [ВЫСОКАЯ] / [СРЕДНЯЯ] / [НИЗКАЯ] уверенность; [НЕ ПРОВЕРЕНО]; [СПОРНО].

## 1. Главный вывод — чистая зашитая рана (без гноя)
1. Первая повязка накладывается в операционной; её не трогают первые ~48 ч, если она сухая и держится [ВЫСОКАЯ].
   - CDC 1999: закрыть первично зашитый разрез стерильной повязкой на 24–48 ч.
   - МЗ Израиля, טופס בקרה מניעת זיהומים, 6.3.7: «חבישה ראשונה מוחלפת לאחר 24–48 שעות על פי נוהל מקומי».
2. Если рану нужно очистить в первые 48 ч — стерильный физраствор [ВЫСОКАЯ] (NICE NG125, 1.4.2).
3. После 48 ч чистый сухой шов обычно ничем не обрабатывают; душ через 48 ч безопасен (NICE NG125, 1.4.3). Если шов разошёлся / вскрыт — можно водопроводной водой (1.4.4).
4. Антисептики и антибиотики НЕ наносят на чистый шов «для профилактики» [ВЫСОКАЯ]:
   - NICE NG125: «Do not use topical antimicrobial agents for surgical wounds that are healing by primary intention».
   - Cochrane (Heal 2016) — местные антибиотики: ограниченная польза, риск резистентности/аллергии → рутинно нет.
5. Вид повязки на инфекцию шва достоверно не влияет [СРЕДНЯЯ]:
   - Cochrane (Dumville 2016, 29 РКИ): неизвестно, снижает ли любая повязка или её тип риск инфекции.
   - ВОЗ 2016/2018: не использовать «продвинутые» повязки вместо стандартных ради профилактики ИОХВ (условная, низкое качество).
6. Снять повязку раньше 48 ч или позже — разницы в инфекциях нет [НИЗКАЯ] (Cochrane, Toon 2015, 280 чел.).

## 2. Спирт на рану
- Спирт — для неповреждённой кожи (уколы, кожа перед операцией), не для раны и свежего шва: цитотоксичен, жжёт, не ускоряет заживление [ВЫСОКАЯ — консенсус, обзоры; прямых РКИ нет].
- Кровотечение спиртом не останавливают: это не гемостатик [ВЫСОКАЯ].
- Утверждение «спирт на ране разжижает кровь» — [НЕ ПОДТВЕРЖДЕНО]: данных о местном антикоагулянтном эффекте не нашёл. Для пациентов писать: «не останавливает кровотечение и повреждает ткани», без «разжижает».

## 3. Повидон-йод («Полидин», «Бетадин») на чистый шов
- Рутинно — нет (NICE NG125, п.4 выше) [ВЫСОКАЯ].
- Наблюдательное исследование (Kaban 2019, 49 пациенток): ранняя перевязка с йодом на 2-е сутки — больше воспаления шва, чем на 5-е [НИЗКАЯ].
- Допустим по клиническому показанию / протоколу отделения; противопоказания: аллергия на йод, болезни щитовидной железы, почечная недостаточность, беременность/кормление, литий (уже на сайте — сохранить).

## 4. Специальные повязки (гидрофибра с серебром, напр. AQUACEL Ag SURGICAL)
- По инструкции производителя — носить до 7 дней; снимать раньше при протекании, сильном кровотечении, усилении боли, подозрении на инфекцию [ВЫСОКАЯ — IFU].
- Патиентские листки NHS по эндопротезированию: менять, когда жидкость дошла до края повязки (UHCW, WWL).
- Исследования в эндопротезировании: РКИ Kuo 2017 (240 пац., колено) — меньше ИОХВ, ношение 5,2 против 1,7 дня; Grosso 2017 (ретроспективно) — меньше острой ППИ. [СРЕДНЯЯ–НИЗКАЯ; часть работ при поддержке производителя]. При этом Cochrane/ВОЗ не подтверждают преимущество в общем.
- Практика нашего отделения 4–5 дней — укладывается в инструкцию (до 7).

## 5. Если повязка промокает кровью
1. Небольшое пятно — норма, повязку оставляют [СРЕДНЯЯ — патиентские листки NHS].
2. Сильное промокание: прижать стерильной салфеткой поверх раны 15–30 мин, не отпуская, чтобы проверить; затем сменить промокшую повязку на стерильную [СРЕДНЯЯ — клиническая практика, листки NHS].
3. Кровит дальше / нарастает отёк / бледность, слабость, учащённый пульс — сразу врачу (в отделении — кнопка вызова; дома — 101) [ВЫСОКАЯ].
4. Пациентам на антикоагулянтах — особенно внимательно, препарат сами не отменять.

## 6. Гнойная / инфицированная рана (раскрытая, заживает вторичным натяжением)
- Основа — хирургическая обработка/санация и антибиотики по решению врача; местное средство — дополнение [ВЫСОКАЯ].
- NICE NG125: не использовать Eusol с марлей, декстраномер, ферментные средства для санации; для вторичного натяжения — подходящая интерактивная повязка.
- Допустимые антисептики для инфицированных/контаминированных ран (немецкий консенсус Kramer 2018; польское общество; IWII 2022; международный консенсус 2023): полигексанид (PHMB), октенидин, гипохлорит/гипохлорная кислота, повидон-йод, серебро [СРЕДНЯЯ — консенсусы].
- Устаревшие и не рекомендуемые: перекись водорода, марганцовка, борная кислота, красители [СРЕДНЯЯ].
- Вакуумная терапия (VAC) — по решению хирурга.
- Израиль: национальный протокол выбора антисептика для гнойных ран НЕ НАЙДЕН [НЕ ПРОВЕРЕНО]. Нужен: протокол больницы/отделения или Israeli Wound Healing Society.

## 7. Расхождения с практикой, о которых говорил Георгий
- «Поливают спиртом и клеят пластырь» — противоречит рекомендациям (п.2, п.5).
- «Максимум физраствором» — верно для первых 48 ч; после — чаще ничем.
- «Хавиша йевеша» на бедре/колене не трогают; Аквасел 4–5 дней — соответствует.
