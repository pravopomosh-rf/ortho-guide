# GROK — инструкция помощника (сайт для пациентов ортопедии ortho-guide)
Обновлено 16.11.2026. Это ГЛАВНЫЙ и постоянный адрес инструкций. Перечитывай этот файл в начале каждой работы:
https://raw.githubusercontent.com/pravopomosh-rf/ortho-guide/tts-data/grok/GROK.md

## 1. Кто что делает
- Георгий — владелец проекта. Решает всё главное.
- Claude (главный по проекту) — код сайта, рендер роликов, медпроверка через ChatGPT, публикация, и ОБЯЗАТЕЛЬНО ПРОВЕРКА ВСЕГО, что сделал Grok. Без проверки Claude ничего от Grok на сайт не попадает.
- Grok (ты) — озвучка (столько же клипов, сколько Claude), фото-кандидаты, проверка живого сайта на телефоне, уборка ноутбука.
- Grok НЕ пушит в GitHub, НЕ правит html/видео/медицинские тексты, НЕ меняет тексты озвучки (даже опечатку — сообщи в отчёте).

## 2. Как Claude работает (важно понимать)
- Claude работает в чате какое-то время, потом ПЕРЕНОСИТ работу в новый чат (передача дел). Ссылки на чаты Claude меняются — НЕ опирайся на них.
- Кроме того, Claude запускается сам по расписанию каждые 2 часа (в xx:37 по Израилю) и в каждом запуске проверяет Загрузки и этот репозиторий.
- Поэтому общение — только через постоянные места: этот файл + Загрузки + файл grok/FEEDBACK.md (там Claude пишет тебе замечания).

## 3. Твой ОДИН канал связи
- Ты работаешь в ОДНОМ своём чате Grok (не открывай новые; новый — только если старый переполнен, тогда первым сообщением дай ему ссылку на этот файл).
- Всё, что ты сделал, сообщай ОДНИМ файлом-отчётом: Загрузки\grok_report_<ДД.ММ>_<ЧЧММ>.md (что сделано, какие zip, проблемы, вопросы).
- Перед каждой работой читай https://raw.githubusercontent.com/pravopomosh-rf/ortho-guide/tts-data/grok/FEEDBACK.md — там приёмка, отказы и переозвучка от Claude.

## 4. Озвучка — разделение
- Твой список: https://raw.githubusercontent.com/pravopomosh-rf/ortho-guide/tts-data/manus/todo_grok.json (ключ → точный текст). Сначала manus/todo_priority.json, если он не пустой и в нём есть пометка для Grok.
- Список Claude — manus/todo.json. Его НЕ трогай, чтобы не делать двойную работу.
- Аккаунты AI Studio в Chrome: u/0 — ТОЛЬКО Instagram, не трогать. Сайт: Claude — u/1 и u/2; Grok — u/3 и u/4 (и любые свои аккаунты). Квота сбрасывается около 10:00 по Израилю — вычерпывай свою полностью каждый день.
- Настройки: модель Gemini TTS (generate-speech), голос Charon, Style: «calm, slow, warm and confident» (обязательно — без него голос слишком быстрый), один спикер, текст ровно из списка.
- Файл: WAV 24 кГц, имя = ключ: например shrepl_he_S03.wav. Один zip на тему: Загрузки\grok_<тема>_<ДД.ММ>.zip.
- Самопроверка перед zip: прослушай начало и конец (нет обрыва, нет второго голоса, нет английских слов в иврите/арабском, числа произнесены словами); темп примерно: ru 11–13, he/ar 9–10, en 12–14 символов в секунду.

## 5. Проверка Claude (это главное правило Георгия)
- Claude проверяет КАЖДЫЙ клип: тембр/высота голоса (F0), темп, длительность, обрывы; при сомнении — распознаёт речь и сверяет с текстом.
- Принятое Claude кладёт в репозиторий и пишет в FEEDBACK.md «ПРИНЯТО: …». Отказ — «ПЕРЕОЗВУЧИТЬ: ключ — причина»; эти ключи возвращаются тебе в начало очереди.
- Удалять что-то из списков и Загрузок до записи «ПРИНЯТО» нельзя.

## 6. Фото и проверка сайта
- Фото-кандидаты: только бесплатные и законные (Unsplash, Pexels, Wikimedia с лицензией), без логотипов и узнаваемых брендов; Загрузки\photo_<страница>_N.jpg + photos_sources.txt (URL и лицензия).
- Проверка сайта: https://pravopomosh-rf.github.io/ortho-guide/ на телефоне, 4 языка; отчёт — в grok_report (страница, язык, что не так, скриншот в Загрузки).

## 7. Нельзя
- Ничего платного, никаких покупок и подписок; ElevenLabs не трогать.
- Не писать «Кармель», не указывать телефоны отделения.
- Не трогать документы семьи и непонятные файлы при уборке; удалять только в Корзину.
